# ✅ Gerenciador de Tarefas

Um sistema web simples e funcional de **lista de tarefas (To-Do List)** feito com **HTML, CSS e JavaScript puro**, sem frameworks ou bibliotecas externas.

---

## 🚀 Funcionalidades

- 📌 **Adicionar tarefas** com:
  - Nome
  - Descrição
  - Data de início
  - Data de fim
  - Prioridade (Alta, Média, Baixa)

- 🧾 **Salvar tarefas no LocalStorage**
  - As tarefas persistem mesmo ao recarregar a página.

- 🧹 **Resetar formulário** ao cancelar ou salvar.

- 📋 **Exibir tarefas formatadas** com:
  - Destaque visual para a prioridade
  - Datas organizadas
  - Descrição e título da tarefa

- 📊 **Ordenação inteligente da lista**:
  - Por **importância** (Alta → Média → Baixa)
  - Por **data mais próxima**
  - Por **data mais distante**

- 🎨 Interface limpa e responsiva com estilo moderno e amigável
